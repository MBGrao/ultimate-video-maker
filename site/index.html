How it works

From brief to post-ready

One request routes through a fixed pipeline. Each step has a free option and a paid upgrade.

Script + hook

Written to a reel format (hook → turn → points → CTA). Hooks are scored, and claims are checked against the live site.

Native voices

ElevenLabs v3 with acting tags. Each language gets a voice picked by audition and Whisper read-back.

Word-pinned timeline

Every effect lands on a spoken word: the slam on "app", the record scratch on "don't".

Pictures + motion

OpenAI images, with a consistent cast from character references. Animated UI in Remotion, where every frame is a function of time.

Composed music

Music is composed to the reel's own sections. SFX land on their words: scratch, swish, boom, ding.

Voice-first mix + QA

Each line is levelled and the music ducks under speech, at −14 LUFS. Whisper re-reads the final mix, and contact sheets catch layout bugs.

Deliver

MP4 with the poster as frame 0, burned-in and .srt subtitles, and an Instagram caption that passes a linter.

Get started

Run it yourself

You need Claude Code and Node 22. Add an ElevenLabs or OpenAI key for paid quality. Without keys, it still runs on free local tools.

git clone https://github.com/MBGrao/ultimate-video-maker
cd ultimate-video-maker/ai-video-skills
./scripts/restore.sh                        # third-party skills, pinned
cp config/.env.example config/.env.local    # add only the keys you buy

# then, in Claude Code:
# "make a 40-second English reel for my-site.com, voice and music included"
